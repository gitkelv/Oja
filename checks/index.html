Conformance checks

What this page proves

The specification's section 6 lists seven interoperability checks. Most of them describe a system working. Three describe it refusing — an invalid network, a denied origin, a run that exceeds its budget. Those are the ones that are easy to skip, because a runtime that fails quietly looks identical to one that works until the day it doesn't.

The checks below run in your browser when this page loads. They need no API key and no model, because none of them involve asking a model anything.
